# LAMP Stack Reference Document

## LAMP Stack Definition

LAMP is a very common software stack of open-source software used for running and operating a web server and web site.

A software stack is a set of software programs that together create a complete platform which needs no additional software to support any given uses or applications (i.e., applications "run on" the software stack).

LAMP is made up of:

- Linux
- Apache
- MySQL (or MariaDB, but in our case we are using MySQL)
- PHP (or Perl or Python, but in our case we are using PHP)

The combination of the above four softwares is very frequently used as the foundation for other web-based applications and for running web servers, which makes it very useful (really necessary) as a basis for running a web server and website.
